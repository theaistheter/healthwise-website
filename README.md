# HealthWise — School Academic Website

## Files
- `index.html` — main website
- `style.css` — responsive design and layout
- `script.js` — navigation and custom registration validation

## How to test locally
1. Keep all three files in the same folder.
2. Open `index.html` in a web browser.
3. Test every navigation link.
4. Test the registration form with empty and invalid fields.
5. Submit a valid fictional entry and confirm that the review message appears.
6. Resize the browser or use mobile view to check responsiveness.

## Hosting
The site is static and can be deployed to an approved static hosting service such as GitHub Pages, Netlify, or Vercel, subject to teacher approval.

## Privacy
Use fictional/sample data only. The form does not send data to a backend or claim to store submissions.

## Health information
The site links to educational resources from:
- World Health Organization (WHO)
- Centers for Disease Control and Prevention (CDC)
- NHS

This project is for academic demonstration only and is not a medical service.
